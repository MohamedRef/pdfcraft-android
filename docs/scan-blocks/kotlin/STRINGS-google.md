# New strings (K05, #307, spec S21)

Format: `name | English text`. The words banned from person-read text are not used in any string below.
The setting is titled "Scanner", not "Scanner engine", for that reason.

scan_engine_title | Scanner
scan_engine_own | PdfCraft
scan_engine_google | Google (needs Google Play services)
scan_engine_google_body | Scanning then happens on Google's screen, and Google's terms apply.
scan_engine_google_unavailable | Google's scanner is not available on this device, so PdfCraft's scanner is used.
scan_engine_google_cannot_run | This device cannot run Google's scanner. The scanner is set back to PdfCraft.
scan_engine_google_failed | Google's scanner did not return the pages. Try again.
