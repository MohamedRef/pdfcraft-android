# PdfCraft Android 0.0.34-beta (34012)

## New features

- **Marker that isn't laid down twice:** where marker strokes of one color cross, or a stroke crosses itself, the color shows once instead of getting darker, and text under it stays black. The marker has flat, chisel ends. A new Straighten lines switch in the marker's options makes each stroke a straight line (part of #569).

## Fixes

- **Eraser works the first time:** strokes you just drew are erased at once, as one undo step, instead of waiting for every stroke to be saved first (#581).
- **Lasso Delete:** Delete, Link and Recolor in the lasso menu act on the selection again. Before, the tap cleared the selection first, so Delete had nothing to delete (#581).
- **No sudden thick lines:** with a light hand, the pen's pressure is no longer stretched up to ten times, so lines stop jumping thick (#581).

## Improvements

- **Older marker strokes:** a marker stroke drawn before this release keeps its look until you edit it. Over white paper, nothing changes.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. Edits on very large files are still slow (#582).
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.34-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.34-beta (34012)` match, then approve the installation in Android. It installs over 0.0.33-beta (33012) with the same package and signing certificate.
