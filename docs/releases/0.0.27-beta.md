# PdfCraft Android 0.0.27-beta (27012)

## New features

- **Save into the original file (opt-in):** when a file manager lends a PDF for reading only, the read-only prompt now offers "Allow saving to original files". After you grant All files access in Android's settings, edits are saved into the original file, including when you reopen it from Recent. Settings ▸ Documents has a "Save to original files" row that shows whether it is on. Nothing changes until you grant it (#491).

- **Markup on a scanned page:** Enhance ▸ More ▸ Markup opens the page full screen with Erase, Pen, Highlighter and Text, each in three sizes. Erase paints the paper's own colour and grain, not white. The marks stay with the page, the scan and Recent scans, and they show up in the saved PDF, in Share and in the gallery (#495).

## Fixes

- **Why a document is read-only:** the read-only prompt now says whether the file was lent for reading only or a save failed during this visit, in all seven languages (#491).
- **Saving in place:** a failed in-place append no longer turns the document read-only. The edit is written over the original when you close it, with the usual recovery copy (#491).

- **Finger removal can be redone:** after Undo, a Remove fingers switch in Enhance's Adjust sheet turns it back on for that page. The over-print note no longer undoes the removal when you tap it (#492).
- **Enhance keeps the page clear:** the automatic look's notes sit in one line under the page, so they no longer cover it. "Flatten this page?" and the Grayscale suggestion are not asked while the automatic look decides them, and look names no longer break inside a word (#493).
- **The pages grid shows each page as made:** cropped, straightened and in its look, and it updates when the page is made again. Recent scans shows the made first page too (#494).

## Improvements

- **Diagnostics log:** each open records why the file is or isn't writable (`source_access`). Failed in-place appends (`write_back_append`) and turning All files access on or off (`all_files_access`) are logged too.

## Known limits and testing

- **These changes have not run on a phone.** It is checked by the Rust and Android JVM tests in CI only. All files access is a standard Android permission that F-Droid allows; the app has no Google dependencies.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.27-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.27-beta (27012)` match, then approve the installation in Android. It installs over 0.0.26-beta (26012) with the same package and signing certificate.
