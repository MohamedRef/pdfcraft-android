# PdfCraft Android 0.0.26-beta (26012)

## New features

- **Scanner, automatic (on by default):** Clean scan decides each page by itself: a receipt turns grayscale, fingers at the page's edge are filled in, and a curled page is flattened only when it comes out straighter. Each step shows an Undo for that page, such as "Flattened · Undo" or "Finger removed · Undo" (part of #466). Every page of a scan is made in the background while you keep shooting (#465).
- **Scan screens in steps (on by default, can be turned off in Scanner testing):** the scanner goes from the photo straight to Adjust borders (#458), then Enhance, with one strip of looks and one bar of icons (#459), then a document screen with the pages in a grid where you can move, select, delete and share pages (#460).
- **Save to gallery:** a scan's pages can be saved as pictures to the gallery's PdfCraft album, with no storage permission (#470).
- **Camera:** camera modes, an icon top bar, zoom and a fixed bottom bar (#457).
- **Open in place:** PDFs opened from other apps are edited where they are, without a private copy in the app (#453).
- **Settings:** a grouped Settings home with one page per topic, About in one place, auto-capture under Scanner, grouped scanner testing options and the last update check time.

## Fixes

- **From the 0.0.25-beta phone log:** Back asks before it discards a scan, and Delete asks before it removes a page (#456); Auto-detect on the crop screen says when it finds nothing (#443); a page whose outline was not found stays a Document until it is cropped (#444); crop lines number pages from 1, and a failed model timing logs why (#445); one curved side no longer makes a Book page.
- **Scanner quality:** Clean scan draws the paper of a grainy page white; the finger search finds real fingers and fills each one; the flattening guard works under shade, on few lines and on whole photos.
- **Opening and closing:** a second open of a file that is still opening, and a second Close during a save, are ignored (#439, #440).
- **Saving:** the original is no longer rewritten when the app pauses for its own file picker (#97).

## Improvements

- **Opening large files:** the reading stage skims the page tree's /Type and /Kids instead of parsing every page object (part of #235).
- **Clean scan preview:** the light estimate is kept with the straightened preview page, so changes redraw faster.
- **Diagnostics log:** a slow page render now names its page (part of #236).

## Known limits and testing

- **The changes in this release have not run on a phone.** They are checked by the Rust and Android JVM tests in CI only. Automatic flattening, finger removal and Scan screens in steps are now on by default; each can be turned off in Scanner testing. Moiré, glare and stains are still only reported (#305, #306).
- Opening timings (#211, #212, #235, #236) wait on the diagnostics log from this build.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.26-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.26-beta (26012)` match, then approve the installation in Android. It installs over 0.0.25-beta (25012) with the same package and signing certificate.
