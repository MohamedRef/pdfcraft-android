# PdfCraft Android 0.0.11-beta (11012)

## New features

- Export a PDF's embedded table of contents as JSON to Downloads.
- Import embedded PDF bookmarks from a system-picked JSON file, appending to existing contents with Undo/Redo.
- Copy embedded bookmarks from another PDF through the system picker. Files that require a password currently show an error; a password prompt is not included yet.
- Tablet and DeX windows can show a collapsible page navigation rail with page jumps, zoom and fit-width controls.

## Fixes

- Preserve uncommitted drawing/tool state when resizing between compact and expanded viewer layouts.
- Close temporary source documents when a bookmark copy is cancelled or fails. Stop SAF staging between chunks when cancelled, without consuming or publishing more chunks.

## Improvements

- Add opt-in opening-stage diagnostics for provider access, native opening, overlays and the first rendered page, to help locate the remaining large-file delay.
- Keep bookmark source files and personal app-local bookmarks separate. Import/copy reject closed, signed or read-only target PDFs and report destinations that do not map to target pages.
- JSON input is limited to 16 MiB, PDF bookmark sources to 512 MiB, using a fixed-size streaming buffer.

## Known limits and testing

- Large PDF opening remains slower than Xodo in the owner's reported tests; no same-file Samsung speed improvement is established. Canvas submission is not a GPU presentation timestamp.
- Physical Samsung S24 Ultra / Tab S11, S Pen, DeX, SAF provider failures, upgrade/data retention and save/reopen tests remain outstanding. Automated checks do not replace those tests.
- Bookmark JSON export may omit branches deeper than the native depth limit. Import/copy report unmapped/truncated destinations; inspect the resulting contents and use Undo if needed.
- Cancellation checks cannot interrupt a provider that is already blocked inside a read call.
- Page background inspection (#30), heading-style contents (#31), and superscript/subscript (#32) are next-batch drafts and are not part of this release.

## Installing

Use the signed `arm64-v8a` APK and accompanying SHA-256 sidecar from this fork’s GitHub Release. The app ID and permanent signing identity are preserved for compatible updates. Android asks for installation approval. Source and CI verification links are added by the publishing workflow below; physical upgrade/data-retention checks remain unverified.
