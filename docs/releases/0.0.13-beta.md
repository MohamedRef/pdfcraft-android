# PdfCraft Android 0.0.13-beta (13012)

## New features

- **Draggable annotation toolbar:** An optional Xodo-style vertical quick toolbar, switched on from More tools, shares the existing saved shortcut order. Drag the dedicated handle to reposition it, release to snap to the nearest left or right edge, and keep the bounded vertical position between sessions. Subtle haptic feedback occurs on pickup and snap only; the original bottom toolbar remains the default.
- **Lasso select and move draft ink:** Draw mode can select strokes from the current editing session and move them as a group within their PDF page. The original stroke appearance/pressure, rendering order and local Undo/Redo are preserved. Already-saved PDF Ink annotations are not affected.
- **Enhance scanned pages:** The native PDFCraft v0.19.0 engine's scan cleanup is now exposed from More tools. Apply to the current page or at most 12 consecutive pages, adjust background cleanup and edge shadows/speckle removal, and confirm before updating the PDF. Unsupported image formats may remain unchanged.

## Fixes

- **Highlight selection:** Fast taps select complete words, forward/reverse dragging snaps words in the same page and the release position determines the final highlight rather than an out-of-date preview.
- **Highlight preview continuity:** The live annotation preview now stays visible while the native edit and page refresh complete, including for highlights created from the text-selection menu. Underline/strikeout use the same completion bridge.
- **Stable text handles:** Improved the long-press selection drag handles, bounded nearest-word fallback, and discarded stale results after cancelling selection.

## Improvements

- Optional left/right docking retains the existing saved QuickToolbarPrefs customization, avoiding two competing tool lists and keeping tool actions unchanged.
- Existing source/provider paths, permanent Android signing identity, app ID, Undo semantics, v0.19.0 native engine and safe release checks remain unchanged.

## Known limits and testing

- Only the **source and CI** can be verified during an automated build. Physical Samsung S24 Ultra, S Pen haptics, Tab/DeX side docking, large-file Xodo timing, edit/save/reopen, provider failures and in-place upgrade/data preservation still require hands-on QA.
- A lasso only selects and moves **uncommitted ink**; editing/resizing saved PDF ink, Xodo full parity and additional freehand Highlight behavior remain future work.
- Some scanned images cannot be enhanced by the engine. Scan enhancement never guarantees changes to every image or that OCR is installed. Review results and undo before saving.
- The updater requires a published owner release; source-only tags, CI artifacts and draft releases do not appear as installed updates. Older APKs remain unchanged.

## Installing

Install `pdfcraft-android-0.0.13-beta.apk` (signed ARM64) from the published release, with its `.sha256` sidecar. Build `13012` is greater than `12012`, and the existing package ID `io.github.mohamedref.pdfcraft` and permanent signing certificate must match earlier releases. Verify the attached SHA-256 and approve installation in Android. The publishing workflow appends its immutable source commit and CI run details after verification.
