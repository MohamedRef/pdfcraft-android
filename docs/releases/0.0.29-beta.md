# PdfCraft Android 0.0.29-beta (29012)

## New features

- **Edit a saved scan from its PDF:** a PDF saved from a scan remembers that scan. Tap a page in the viewer, choose Edit to open it in the scanner with everything as it was, then save back into the same PDF (#513).
- **Borders and looks for several pages at once:** on the document screen, selected pages get Borders and Look. Borders goes through the chosen pages one by one, with Previous and Next (#515).
- **Every scan tool in reach:** Enhance's bottom bar has Borders, Markup, Rotate, Retake and More, and Delete moves to the page's top bar. The document screen shows Select, and scans appear on Home (#516).
- **Unlock PDF:** a tool of its own to remove a PDF's password and restrictions, reachable from the Tools hub, the tool list and Set password (#517).
- **Text selection menu:** Copy first, then Select all, Find in document and Share. The rest sit behind More, together with other apps' text actions such as translate or define (#523, #535).
- **Document name in the top bar:** the name stays visible, cut in the middle when it's long, with the save state under it. Tap it to open File details (#525).
- **Fit each page to the width:** in the continuous view, pages of different widths can each fill the width (Fit each page in the view sheet) (#524).

## Fixes

- **Adjust borders:** a corner or side you're dragging is pulled onto the paper's edge while you drag, not only after you lift your finger (#514).
- **Draw toolbar:** every tool on the second row can be reached again. Before, on a narrow phone, Arrow, Cloud, Polygon, Lines, Ruler, Protractor and Zoom box had no width (#522).

## Improvements

- **Diagnostics log:** new lines for the scan edit link, the drag pull, the batch passes, the selection menu and fit-each-page.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. The scan changes follow testing options that are on by default and can be turned off in Scanner testing.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.29-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.29-beta (29012)` match, then approve the installation in Android. It installs over 0.0.28-beta (28012) with the same package and signing certificate.
