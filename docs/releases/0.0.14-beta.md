# PdfCraft Android 0.0.14-beta (14012)

## New features

- **Five annotation pen styles:** Ballpoint, Fountain, Pencil, Brush and Freehand Highlighter, with selectable nib previews, pressure-responsive width profiles where applicable, and transparent marker strokes. The freehand marker uses native PDF Ink with the FreehandHighlight intent; text-selection highlighting remains separate.
- **Samsung Notes-inspired pen picker:** Redesigned pen favorites, illustrated nibs, interactive color, width and opacity controls, and more distinctive annotation icons. Three favorites remember pen style as well as appearance and migrate older slots safely.
- **Explicit drawing shapes:** Straight line, rectangle and oval tools beside existing freehand ink and shape recognition.
- **Resumable APK updates:** About > Check for updates keeps interrupted downloads in a private location, requests the missing bytes when supported by the server, shows Pause/Resume and progress, and restarts safely if the server ignores Range. Updates still require explicit installation approval.
- **Improved What's New:** Organized release notes show Features, Fixes, Improvements and expandable Known limits instead of truncating the release description to 300 characters.

## Fixes

- Preserve pen appearance across strokes and saved presets when switching between nib types.
- Use the original native PDF annotation pathways for saving freehand highlighter appearance; preview uses Multiply blending consistent with native marker appearance.
- Preserve legacy Android updater SHA-256, package-name, version-code, signer, ARM64 engine and HTTPS validation before passing the APK to the Android installer.
- Keep the updater and annotation strings together when merging their independent pull requests.

## Improvements

- Bounded stylus pressure runs remain safe for long strokes, with existing palm rejection, hardware eraser routing and draft Undo/Redo.
- The mobile pen picker scrolls on compact screens; direct shapes stay bounded to their source page.
- Resumable downloads use content-addressed partial filenames and exact HTTP Content-Range checks, avoiding corrupt concatenation.

## Known limits and testing

- Test results from GitHub Actions validate source code and Android JVM/Rust suites; they do not replace physical Samsung Galaxy S24 Ultra and S Pen handwriting, palm rejection, stylus-button, low-storage, rapid pause/resume and export/reopen testing.
- Fountain/Pencil/Brush use pressure and width profiles saved as PDF Ink segments, not proprietary brush-texture raster engines. Pencil does not include paper grain and Fountain is not a tilted calligraphy engine.
- Existing PDF files preserve rendered annotation appearance, but a specific UI nib-type identifier is not a portable PDF annotation property.
- The updater resumes after the user returns to the app and retries; there is no continuous background download service after a force-stop. If a server rejects Range, the download safely restarts.
- The installation signature and upgrade identity must still match; do not install a differently signed APK over an earlier release.

## Installing

After the combined pen, annotation and updater PRs pass all required checks, install the separately published owner-signed ARM64 APK `pdfcraft-android-0.0.14-beta.apk` from this repository's GitHub Releases. Verify the attached SHA-256, inspect the exact manifest build `14012`, and confirm installation in Android. The release publishing workflow appends exact source commit and CI run evidence.
