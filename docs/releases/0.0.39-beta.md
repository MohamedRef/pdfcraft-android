# PdfCraft Android 0.0.39-beta (39012)

## New features

- **Compress shows its progress:** Compress shows the page being read and the image being compressed, with a progress bar and a Cancel button that stops it (part of #634).

## Fixes

- **A message behind an error waits:** a message raised while an error is on screen now waits and is shown after the error's 3 seconds, and a second error gets its own 3 seconds (#635).
- **Undo in a message:** a message's Undo button is no longer used up by a stroke that is still a draft (#635).
- **Message width:** the message box is as wide as its message and centred (#635).
- **Close all asks first:** Close all on the open-documents bar on Home asks before it closes the open documents (#636).

## Improvements

- **Correction to the 0.0.38-beta notes:** the 0.0.38-beta notes said that long jobs other than text recognition are counted and can be stopped. Only Compress, Export to images, Combine, Create PDF and saving files are counted and can be stopped. Split, Extract, Export, Print, Compare and Protect are not yet (#634).

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.39-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.39-beta (39012)` match, then approve the installation in Android. It installs over 0.0.38-beta (38012) with the same package and signing certificate.
