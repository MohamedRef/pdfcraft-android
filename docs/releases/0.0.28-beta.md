# PdfCraft Android 0.0.28-beta (28012)

## New features

- **File size choices at Save:** Save PDF and Share open a sheet with Best quality, Balanced (the default), Small and Smallest. Each choice shows this scan's estimated size and is remembered. At Small and Smallest, "See this page as it will be saved" shows the page as it will be stored (#505).
- **Each page stored by what is on it:** a page with no colour is stored in grey, a text-only page can be stored in black and white at Small and Smallest, and resolution follows the finest print on the page. A new JPEG encoder makes tables for each page. Together these make scans smaller at the same quality (#505).
- **Save at once:** pages are made at full size ahead of time while you work, so Save PDF, Share and Save to gallery only finish the pages that aren't ready yet ("Finishing page n of m") (#504).
- **Text recognition only when asked:** Settings ▸ Scanner ▸ "Make the text selectable", off by default. When it's on, Skip in the dialog saves the PDF straight away (#504).
- **Markup colours:** More colours in Pen, Highlighter, Text and Erase opens the same colour sheet as the viewer's pen, with recent colours, palettes and a custom colour. An eyedropper with a magnifier picks a colour from the page. Erase can fill with the paper around it, with a picked colour, or by following the edges around it (#503).

## Fixes

- **Scanner:** deleting several pages could crash on Android 10–14. Fixed (#502).
- **Study:** importing a card file failed on Android 10–12. Fixed (#507).
- **A check so these don't come back:** CI now runs Android lint's NewApi check, which fails the build on calls that need a newer Android than the app supports.

## Improvements

- **Smaller scanned PDFs:** on the test form page, per-page tables alone save about 22%, half-resolution colour saves about 20% more, and grey saves 28–43% on pages with no colour (#505).

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. Text recognition at Save is now off by default.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.28-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.28-beta (28012)` match, then approve the installation in Android. It installs over 0.0.27-beta (27012) with the same package and signing certificate.
