# PdfCraft Android 0.0.15-beta (15012)

## New features

- **Direct-access drawing toolbar:** A two-row pen-first interface shows Ballpoint, Fountain, Pencil, Brush, Freehand Highlighter, Eraser and Lasso on the first row, with three pen favorites, color, pen settings and line/rectangle/oval shapes directly accessible on the second. Narrow phone layouts allow horizontal scrolling without automatically jumping away from the selected tool.
- **OCR word-confidence review:** Inspect the current PDF page's native OCR word confidence through a read-only, bounded suspect-first review list. This does not change recognized text or alter the PDF.

## Fixes

- **Freehand Highlighter erasing:** The Android ink eraser opts in to safe native erasure of unlocked FreehandHighlight Ink, not text highlights, locked annotations or Fill & Sign ink.
- **Tap-only pen dots:** A single pen tap is retained as a microscopic two-point PDF Ink path rather than silently disappearing.
- **Marker stroke preservation:** Freehand Highlighter strokes are no longer accidentally recognized and transformed into geometric shapes by automatic Snap.
- **Tool selection:** Switching from Eraser or Lasso to a pen or saved favorite returns to writing mode. Shape tools select the last writing pen rather than leaving the translucent marker active.

## Improvements

- Distinct original nib silhouettes and ink samples differentiate the five pen profiles without reusing proprietary Samsung Notes assets.
- Clear active-state treatment, 48dp tool targets and responsive two-row layout make drawing actions easier to find, including on narrower Android windows.
- Pen-only/S Pen input and Snap-to-shape explanations are visible inside the pen settings; the document viewport accounts for the expanded drawing controls.
- Existing v0.19.0 mobile engine, bookmarks, resumable signed updates, PDF editing pathways, app identity and saved pen presets remain unchanged.

## Known limits and testing

- Automated Rust/provenance, Android JVM, UI and signed ARM64 release checks cannot substitute for on-device Samsung Galaxy S24 Ultra, S Pen and tablet/DeX handwriting, pressure, haptics, latency, palm rejection, 320dp width, large text, zoom, PDF export/reopen and installation upgrade tests.
- Fountain, Pencil and Brush use distinct pressure/width/opacity profiles stored as PDF Ink runs. They are not proprietary texture or calligraphy engines; pencil grain and angled fountain strokes are not implemented.
- The native eraser can target freehand highlight Ink when enabled; text-selection highlights and locked or Fill & Sign annotations are deliberately excluded.
- OCR confidence is a read-only diagnostic, not OCR correction or full editable text recovery. A scanned PDF may return few or no useful words.
- Resumable APK download requires returning to the app and restarting a stopped transfer. Android still asks for installation approval and requires a matching certificate.

## Installing

After the exact source, test, release-signing, ABI, manifest build and checksum verification gates succeed, install `pdfcraft-android-0.0.15-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's published GitHub Release. Verify the associated SHA-256 and manifest version `0.0.15-beta (15012)`, and approve installation through Android. Do not replace the older published release or rotate the original owner signing certificate.
