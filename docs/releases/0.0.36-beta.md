# PdfCraft Android 0.0.36-beta (36012)

## New features

- **Erase whole strokes:** the eraser's size sheet has an Erase whole strokes switch, off by default and remembered. When it's on, any stroke the eraser touches is removed whole, as one undo step per gesture (#521).

## Fixes

- **Ink drawn just before closing is kept:** closing a document right after drawing could close it before the new strokes were saved, so they were lost. Saving now waits for strokes that are still being added (#597).
- **Jetpack Ink pens no longer close the app:** in 0.0.35-beta, turning on Try Jetpack Ink pens in Pen lab closed the app on the first stroke. The pen's pressure is now passed correctly, and if Jetpack Ink fails, PdfCraft's own pen draws the stroke instead (#592).
- **Update download paused in the background:** leaving PdfCraft while an update downloads no longer fails it. The download pauses and continues by itself from where it stopped when you come back. This works from 0.0.36-beta on, so the download of 0.0.36-beta itself still needs Resume (#596).
- **Slow edits on large files:** each comment, drawing or erase no longer copies the whole file. A file opened in place is extended with the change instead (#582).

## Improvements

- **Clearer error names in the diagnostics log:** errors are logged with their real class names instead of shortened ones (#596).
- **Edit speed on large files:** measured on a computer only, not yet on a phone. Four drawings on a 100 MB file took 3 to 8 ms instead of 68 ms, and on a 50 MB file 5 to 6 ms instead of 34 to 37 ms. Small files are unchanged.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. The speed-up above needs the phone's diagnostics log to confirm.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.36-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.36-beta (36012)` match, then approve the installation in Android. It installs over 0.0.35-beta (35012) with the same package and signing certificate.
