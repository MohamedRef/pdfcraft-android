# PdfCraft Android 0.0.30-beta (30012)

## New features

- **Markup ink on the screen:** in a scan's Markup, the pen, highlighter and Color strokes are drawn right on the screen, and Undo, Redo and Clear show at once. Paper, edge and Color fills are drawn as a patch, the pen follows your finger with less delay, and a slider sets its size (#520).
- **One list of tools:** Home ▸ Tools and the viewer share one list of 31 tools by category, with Scan first. Home Tools gets search, smaller tiles and category headings, and More tools has more tools (#539).
- **Print and Study in the viewer menu:** one Print row opens Print options, with the Print comments switch near the top. A Study heading in ⋮ holds the focus timer, Study, Lecture recordings and Flashcards. Sub-tools get captions, Squiggly has its own icon, and the page pill is 48 dp (#526).

## Fixes

- **Tool bars on narrow phones:** the Edit PDF bar and the Pages screen bar share their width, so no button is pushed off the screen. Before, Link had no width at 360 dp (#538).
- **Markup's Back:** the Back arrow and the Back gesture keep your marks, as Done does (#531).

## Improvements

- **Saving a scan:** a page made ahead is kept at all four sizes, so whichever size you pick at Save is ready (#528).

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. Markup ink follows a testing option that is on by default and can be turned off in Scanner testing.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.30-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.30-beta (30012)` match, then approve the installation in Android. It installs over 0.0.29-beta (29012) with the same package and signing certificate.
