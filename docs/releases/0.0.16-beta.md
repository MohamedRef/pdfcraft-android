# PdfCraft Android 0.0.16-beta (16012)

## New features

- **Desktop engine v0.20.0:** The mobile engine now matches upstream PdfCraft v0.20.0 for its 32 mobile crates, keeping every Android adaptation (voice comments, photo detection, sticky-note overlay, timestamp discovery; 3D/PRC still excluded). New engine commands such as object copy/paste, hairline fix and text preparation are available to the engine but have no dedicated Android screens yet.
- **One annotation per pressure stroke:** A pen stroke with pressure is now saved as a single Ink annotation with a width per point, instead of up to 64 separate pieces. Tapping, moving, recolouring and erasing act on the whole stroke, and translucent ink no longer shows darker dots at the joins. Other PDF viewers show the stroke at its average width.
- **New annotation tools:** Squiggly (wavy underline) in Markup and the text selection menu; Arrow and Revision cloud in Draw, saved as real PDF arrow and cloud annotations; Stamp mode in Comment with the 17 standard stamps; and Callout mode in Text, with the box placed beside the tapped point.
- **Lasso on saved writing:** The Draw lasso also selects saved drawings and shapes (not text markup, replies, locked or Fill & Sign items). Move them, apply the current pen colour or delete them; one Undo restores the whole change.
- **Real pen pressure and a predicted tail:** Samples between screen frames now use the pressure the pen actually reported instead of an estimate, and a short predicted tail is drawn where the pen is about to be while writing. The tail is never saved.

## Fixes

- **Handwriting is no longer turned into shapes:** Snap to shape only applies to a stroke you hold still, and only with the setting on. Lifting the pen never turns a handwritten l, 1, o or 0 into a line or oval.
- **Draft ink before page changes:** Unsaved strokes are saved before the Pages screen opens, so deleting, moving or rotating pages no longer puts them on the wrong page, and Organize's Undo undoes the page change.
- **Discard keeps a damaged file's recovery copy:** After a failed save to another app's storage, Discard no longer deletes the edited copy when the original no longer looks like a complete PDF. PdfCraft keeps the copy and offers it again on the next open.
- **Voice comment length:** Recording now stops at 17 minutes (warning at 16), so a recording is never rejected for being over the engine limit. The temporary recording file is removed afterwards.
- **Security:** An app package (such as `.apk`) attached inside a PDF is no longer handed to Android's installer. Another app can no longer make PdfCraft open and overwrite files in PdfCraft's own private storage through a `file://` link.
- **Update downloads:** Short network drops, timeouts and temporary GitHub/CDN errors are retried automatically, and a download that keeps advancing is not stopped by the retry limit. A browser download link is offered as a fallback.

## Improvements

- Writing stays smooth during long sessions: unsaved strokes are no longer redrawn point by point on every frame.
- The stroke preview uses the same smoothing as the saved stroke, so it no longer changes shape after saving.
- After a comment edit, erase or stroke, only that page is rendered again; zoomed pages no longer blur for a moment.
- New and updated texts are translated into Arabic, German, Spanish, French, Italian and Brazilian Portuguese.

## Known limits and testing

- Automated Rust/provenance, Android JVM and signed ARM64 release checks passed. None of this replaces physical tests on a Samsung Galaxy device with S Pen: pressure feel, the predicted tail, palm rejection, long handwriting pages, the lasso on saved writing, page edits and saving to other apps' storage.
- Saved pressure strokes have not yet been checked visually in Acrobat or Xodo; they should follow the drawn appearance, and viewers that redraw ink from its points show the average width.
- The lasso selects saved items by their rectangles, not exact stroke shape. Recolour applies to saved items only, and resizing a selection is not available yet.
- Moving a saved selection is one Undo step; drafts and saved items in one selection keep separate undo histories.
- PR #66 was merged while an earlier cancelled run still showed a failing check (issue #206). The main build after it passed, and this release is built from a fully passing main.
- Many reviewer findings are open as issues (#70–#205); see the repository for known problems.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.16-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.16-beta (16012)` match, then approve the installation in Android. It installs over 0.0.15-beta (15012) with the same package and signing certificate; earlier releases are not replaced.
