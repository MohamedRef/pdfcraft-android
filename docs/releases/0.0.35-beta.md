# PdfCraft Android 0.0.35-beta (35012)

## New features

- **Pencil with paper grain:** a light touch lets the paper show through a fine grain, and a firm press fills it in. Leaning the pen far over widens and lightens the line for shading; ordinary writing angles are not shaded. The grain is saved in the PDF the same as you see it. Pen lab has new "Ink and paper" dials (part of #569).
- **Try Jetpack Ink pens:** Pen lab has a switch, off by default, that lets Jetpack Ink draw the ballpoint, fountain pen and brush, so you can compare them with PdfCraft's own pens. Saved strokes, the eraser, the lasso and Undo work the same either way (part of #569).

## Fixes

- **Erasing a pencil line:** the pieces left after erasing keep their grain.

## Improvements

- **Older pen settings:** pen settings saved by an older version still load.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. Jetpack Ink's drawing needs the phone to judge; if it can't load, PdfCraft's own pens draw instead. The APK is about 1.3 MB larger for it.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.35-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.35-beta (35012)` match, then approve the installation in Android. It installs over 0.0.34-beta (34012) with the same package and signing certificate.
