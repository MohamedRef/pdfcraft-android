# PdfCraft Android 0.0.24-beta (24012)

## New features

- None in this release; it fixes a regression and speeds up preparation.

## Fixes

- **Thumbnails of large files are back:** 0.0.23 showed a plain PDF icon instead of the first page for files over 100 MiB in Recent, because file-list previews were limited to copying 100 MiB. A working copy in PdfCraft's own store is now read through the same read-only mapping the viewer uses, without a copy, at any size the viewer opens. Other files keep the 100 MiB preview limit.

## Improvements

- **Faster full preparation of large annotated files:** The page structure inspection reads all page annotations on up to four threads before going through them, and the search for document timestamps across the whole file runs on up to four threads. Both give exactly the same results as before (tested). On the owner's phone in 0.0.23 these took about 1.3 s and 0.9 s of the 2.7–3.0 s before editing was available.
- **Display copy from a mapped file:** When comments without their own appearance require PdfCraft to draw a copy of the file, a mapped file is now read ahead for that copy. In 0.0.23 this copy took 0.57 s on the owner's phone, against 0.13 s when the file was held in memory.

## Known limits and testing

- The parallel work needs several cores; on a 2-core test machine it showed no gain, so its effect on a phone is not yet measured. The read-ahead hint is not measured either.
- Files with comments that have no saved appearance (common from some other PDF apps) still need a full drawn copy of the file in memory before editing; avoiding that copy is open work. Such a comment on the first page also keeps the reading stage from showing that page early.
- Automated Rust/provenance (including tests that the parallel inspection and timestamp scan give identical results, and the thumbnail mapping and its limits), Android JVM and signed ARM64 release checks passed. Not verified on a physical device.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.24-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.24-beta (24012)` match, then approve the installation in Android. It installs over 0.0.23-beta (23012) with the same package and signing certificate; earlier releases are not replaced.
