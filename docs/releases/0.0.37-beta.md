# PdfCraft Android 0.0.37-beta (37012)

## New features

- **Pens write one even line:** the fountain pen and the brush no longer swell into a blob in the middle of a stroke. How fast a line may get thicker or thinner is now limited by how far the pen has moved, so a harder press, a pause or a corner widens the line gently instead of all at once (#601).

## Fixes

- **Mid-stroke blobs:** in 0.0.36-beta one fountain stroke went from 0.63 pt to 8.34 pt and one brush stroke from 0.18 pt to 35.5 pt. The fountain pen now stays between half and one and a half times the chosen width, and the brush between a quarter and 1.8 times (#601).
- **Short strokes and dots:** a short stroke with a thick pen no longer swells to full width when the pen lifts, and a dot is drawn as one even round dot (#601).
- **Finger writing:** a line drawn with a finger no longer starts at its thickest, and its width stays in the middle of the pen's range (#601).
- **Samples without pressure:** a pen sample that carries no pressure keeps the last pressure instead of counting as the hardest press (#601).

## Improvements

- **The chosen width is the width you write:** the pen size you pick is now the width of ordinary writing. Pens set very wide to make up for the old thin lines, such as 13.8 pt, now write about that wide and may need to be set back down.

## Known limits and testing

- **These changes have not run on a phone or tablet.** They are checked by the Rust and Android JVM tests in CI only. The new pen tests use made handwriting shaped to the numbers in the 0.0.36-beta log, not strokes recorded from a real pen.
- **Pen lab values reset once:** dial values that Pen lab saved in an older build are dropped one time, because the dials now mean something else. The pressure curve and the measured pressure range are kept.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.37-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.37-beta (37012)` match, then approve the installation in Android. It installs over 0.0.36-beta (36012) with the same package and signing certificate.
