# PdfCraft Android 0.0.42-beta (42012)

## New features

- **Text markups next to the pens:** Draw's bar holds Highlight, Underline, Strike and Squiggly after the eraser and lasso, one tap away. Highlight's bar starts with Draw and Eraser, one tap back to the pen or the eraser (#660).
- **The eraser removes a text markup:** the eraser removes a highlight, underline, strikeout or squiggly it touches, whole, in one undo step (#660).
- **Every open document as cards:** a number at the start of the tab strip, and the count on Home's open-documents bar, show every open document as cards with its name, a picture of its page and "Page n of m". A tap brings it to the front, ✕ closes it, and the bar has Close others or Close all, which ask first (#669).
- **Contents at the side on every tablet:** a tablet always shows the contents in a side panel, never the sheet. From 780 dp wide the panel sits beside the page; narrower, it slides in over the page. A strip at the side has the Pages, Contents and Bookmarks icons, and whether the panel was open is remembered for each document (#659).

## Fixes

- **Large books opened in place no longer use more and more memory:** saving a book opened in place no longer copies the whole file into memory, so memory stays flat over several saves and edits instead of growing until Android closes the app (#654).
- **Files from chat and mail apps are copied:** a PDF sent from WhatsApp, Telegram or a mail app is copied before it opens, even when it could open in place, and Recent reopens the copy. A file manager still opens files in place (#656).
- **Text markups mark the exact letters:** a drag marks the letters it covered, not whole words, and may start or end beside its line. A page with text never gets a free box; only a page without text, such as a scan, does (#657).
- **Fountain pen and brush dots:** a dot no longer grows after the pen lifts. A pen that rests where it came down fills its dot while it is on the page (#661).
- **Closing a file from another app:** closing it leaves PdfCraft only when it was the last open document, and a file continued in a copy no longer leaves its original's tab behind (#662).

## Improvements

- **Pull request checks:** the title check no longer depends on a GitHub event that GitHub is starting to block, so merges are not held up by it (#663).

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only. The memory use of a large book over several saves needs the diagnostics log from this build.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.42-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.42-beta (42012)` match, then approve the installation in Android. It installs over 0.0.41-beta (41012) with the same package and signing certificate.
