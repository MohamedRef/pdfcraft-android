# PdfCraft Android 0.0.12-beta (12012)

## New features

- **Bates numbering across PDFs:** Tools → Bates numbering lets you order saved PDFs, choose a starting number, minimum digits, prefix and suffix, and export consecutively numbered copies to Downloads. Originals remain intact; each file reports its saved range or failure.
- **Favorite pens:** Draw → Favorite pens stores three combinations of color, width and opacity. Use a favorite or explicitly replace it with the current pen. Existing strokes, author, pressure and pen-only settings stay independent.

## Fixes

- Keep Android voice-comment microphone appearances while adopting the updated annotation engine.
- Reject clipboard selections containing embedded recordings or file attachments when their data cannot be transferred safely; original recordings and files remain intact.
- Respect PDF object generations during Android's timestamp candidate discovery, retaining full signature validation.

## Improvements

- Update the mobile-suitable PDF engine to stable desktop v0.19.0, including upstream parsing/encryption, rendering, forms, OCR, scan, redaction and signature validation changes while retaining Android integrations.
- Add native OCR review/dictionary, scan enhancement and comment-transfer commands. Their presence does not mean every desktop workflow has a dedicated mobile screen.
- Validate batch numbering ranges before exporting, bound source copying, clean up new pending downloads on failure/cancellation, and retain ownership of already committed results.
- Validate persisted pen profiles and fall back safely when a slot contains corrupt or unsupported data.

## Known limits and testing

- Large-PDF opening remains unresolved on the owner's Samsung/Xodo comparison. Warm-cache Mac native/raster timings are not Android provider/UI/GPU timings or proof of a phone speed improvement.
- Physical Samsung S24 Ultra / Tab S11, S Pen, DeX, RTL/accessibility, upgrade/data retention, provider failures, Downloads publication and save/reopen trials remain outstanding.
- Bates accepts up to 20 PDFs and 512 MiB total input. It reads saved files; save open edits first. Start is limited to 12 digits, minimum digits to 1–12, and prefixes/suffixes must be short and cannot contain # or >>.
- Bates rejects signed or structurally read-only PDFs. Password prompts are not included; encrypted PDFs must open without a password. Native editing permissions remain authoritative.
- Cancellation cannot interrupt a provider already blocked inside a read or an in-flight native batch. It stops further exports once control returns. Copies saved before cancellation or later failures remain in Downloads; a batch is not an all-or-nothing publication transaction. Rerunning can create additional copies.
- Favorite pen storage covers appearance only. Lasso/move/resize/handwriting and full Xodo parity remain future work.
- Optional external Tesseract is not bundled or downloaded; the existing pure-Rust OCR engine remains the default. Desktop 3D/PRC commands remain deliberately excluded.
- Automated checks and the full local engine workspace do not replace physical device validation. Source/provenance, Android JVM/ARM64 and signing/manifest/hash evidence is recorded with the publishing workflow below.

## Installing

Use this fork's signed ARM64 APK and SHA-256 sidecar. The package and permanent signing identity are preserved; Android asks for installation approval. Actual manifest build and source/CI links are appended by the publishing workflow after verification.
