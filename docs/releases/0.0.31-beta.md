# PdfCraft Android 0.0.31-beta (31012)

## New features

- **Document categories:** a document can be in Study, Work, Personal or a category of your own. Set it with one tap on a chip from the file's ⋮ sheet on Home and Files, the Library, the viewer's ⋮ sheet, or by holding a row of Home's card. Add, rename, delete and reorder categories from the pencil next to the chips or Settings ▸ Library ▸ Edit categories (#560).
- **Home's card follows the category:** chips for All and each category in use. Study shows "Continue studying", this week's time and flashcards for Study documents only; the others show "Continue reading". A row appears only after one minute of reading.
- **A suggestion, never a silent change:** after tape, a quiz, a flashcard, a lecture recording or the focus timer on a document with no category, the card asks once whether to add it to Study.

## Fixes

- **Duplicate rows on Home's card:** the same file opened two ways, such as from the file picker and from On device, is now one row, with its time added up (#560).

## Improvements

- **Library:** a chip for each category in use, and item rows show the category. Edit categories shows this week's time per category.
- **Diagnostics log:** new `study` lines for setting a category, the suggestion, the card and merged records.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. Merging existing duplicate rows needs a diagnostics log from a phone to confirm.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.31-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.31-beta (31012)` match, then approve the installation in Android. It installs over 0.0.30-beta (30012) with the same package and signing certificate.
