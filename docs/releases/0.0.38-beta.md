# PdfCraft Android 0.0.38-beta (38012)

## New features

- **Pressure setting for each pen:** each writing pen's options have a Pressure slider, from 0 % (one even width) to 100 % (twice the usual change with pressure), 50 % at first and kept per pen (#608).
- **A light hand writes in the middle of each pen:** a light pressure is now spread across the pen's range, so ordinary writing lands near the chosen width instead of at its thin end, and the brush answers pressure more than the fountain pen (#608, #607).
- **Start a scan from photos already taken:** a scan can begin from pictures in the gallery instead of the camera (#617).
- **Tablet layout:** outside the viewer, a tablet shows a side rail, readable text widths and a wider grid (#613).

## Fixes

- **Messages at the bottom of the screen:** messages no longer queue up. A new message replaces the one on screen at once, Undo and Redo show one message updated in place that goes away about 2 seconds after the last tap, the same text is not shown twice in a row, an error is not hidden by a routine notice, a swipe closes a message without another coming up behind it, and a message goes away when its document or screen closes (#618).
- **Pointed ends while you write:** a pen's pointed end is drawn while the stroke is written, not only when the pen lifts (#611).
- **Night Mode ink:** unsaved strokes look the same as saved ones in Night Mode, and the marker and the default pens show on dark paper (#610).
- **Pressure band:** a light hand's pressure band is widened the same way however narrow it is, and only ordinary writing on a page measures it, not the Pen lab strip or the marker (#607).
- **Home on a phone:** three recent files are shown, and the bar of open documents stays on one line (#615).
- **Long jobs:** long jobs other than text recognition are counted, can be stopped and are timed in the diagnostics log (#614).
- **Translations:** every missing string is translated, and a check now stops a build that leaves one out (#616).

## Improvements

- **Lighter, faster ink:** a line keeps a point every 0.75 dp instead of every pen sample (about a third of the points), its outline is one ribbon instead of a disc and a piece per point, and only the newest points are redrawn while you write. On the test sheet, six strokes went from 532 KB to 46 KB in the file (#609).
- **Finished strokes as a picture:** while drawing, strokes already finished are kept as one picture and only the stroke being written is drawn live. **Settings ▸ Pen lab ▸ Keep finished strokes as a picture** turns this off; it is on by default (#609).
- **Jetpack Ink trial removed:** the Try Jetpack Ink pens switch and its library are gone; PdfCraft's own pens are used everywhere.

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only, on made strokes and test layouts. Pen feel, frame times and file sizes on a device need the diagnostics log from this build.
- If finished strokes ever look wrong while drawing, turn off Keep finished strokes as a picture in Pen lab.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.38-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.38-beta (38012)` match, then approve the installation in Android. It installs over 0.0.37-beta (37012) with the same package and signing certificate.
