# PdfCraft Android 0.0.33-beta (33012)

## New features

- **Smoother pen lines:** the pen's line is smoothed as you write. A slow pen, where a wobble shows, is smoothed most; a fast pen hardly at all, so the line never trails behind. Each pen has a Line smoothing slider in Pen lab (part of #569).
- **Pressure curve:** Pen lab has one pressure curve for every pen, with three points you drag. A harder press never gives a thinner line, and "Make the curve straight again" resets it (part of #569).
- **Fountain pen nib:** the fountain pen's width now follows an elliptical nib, so the line changes smoothly with direction instead of with a kink (part of #569).

## Fixes

- **The line reaches the pen:** while you write, the line is drawn all the way to the pen tip, on the page, in the zoom pad and in Pen lab's strip (part of #569).
- **Harder presses still count:** your measured pressure range now sits between 10% and 90% of each pen's width range, so pressing harder than usual still thickens the line (part of #569).

## Improvements

- **Same feel on phone and tablet:** the pen's speed is measured on the glass rather than on the page, so one set of pen settings works on phone, tablet and at every zoom (part of #569).
- **Diagnostics log:** stroke lines name the smoothing and the screen-to-page scale, and the Pen lab values include the pressure curve.

## Known limits and testing

- **These changes have not run on a phone or tablet.** They are checked by the Rust and Android JVM tests and Android lint in CI only. The pen settings are first guesses for tuning in Pen lab.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.33-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.33-beta (33012)` match, then approve the installation in Android. It installs over 0.0.32-beta (32012) with the same package and signing certificate.
