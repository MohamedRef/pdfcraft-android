# PdfCraft Android 0.0.32-beta (32012)

## New features

- **Each pen writes its own way:** Ballpoint, Fountain, Brush and Pencil now differ in how pressure, speed and the nib's angle change the line, with pointed starts and ends. What you see under the pen is what stays on the page. Finger strokes vary with speed too. The app learns your pen's pressure range from your first few strokes (part of #569).
- **Pen lab:** Settings › Diagnostics › Pen lab has a slider for each pen setting, a strip to try the pen on, and the measured pressure band, with Reset and a button to write the values to the log.

## Fixes

- **Draw eraser:** erasing works again. Before, every erase was refused (#572).
- **Files from chat and mail apps:** a PDF that WhatsApp, a mail app or another app lends for one visit is copied into the app, so Recent can open it again later. Files from My Files still open in place (#476).
- **A file cut short by another app:** if the app that lent a PDF shortens it while it's open, PdfCraft no longer closes suddenly (#476).
- **Engine messages in your language:** error messages from the PDF engine are shown in the app's language instead of English (#118).

## Improvements

- **Writing:** low-latency ink is removed. On the test phone it was slower than the normal path (13 ms against 5 ms at p95, at 60 Hz instead of 120 Hz). Its switch in Pen settings and Scan Markup's low-latency pen go with it (#128).
- **Faster checks:** the Rust tests build with less debug information, so new versions come out sooner (#566).
- **Diagnostics log:** an engine tool that refuses now logs why, and every ink stroke logs its pen, pressure, speed, tilt and width.

## Known limits and testing

- **These changes have not run on a phone.** They are checked by the Rust and Android JVM tests and Android lint in CI only. The pen settings are first guesses for tuning in Pen lab.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.32-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.32-beta (32012)` match, then approve the installation in Android. It installs over 0.0.31-beta (31012) with the same package and signing certificate.
