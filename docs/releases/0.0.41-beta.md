# PdfCraft Android 0.0.41-beta (41012)

## New features

- **Contents in one tap:** the reading page's top bar has a Contents button that opens Bookmarks & contents directly. On a phone it takes Share's place on the bar, and Share is in More, under File (#647).
- **Contents as a tree:** a chevron opens a chapter where it stands instead of one level at a time. Each entry shows the page it goes to, and the section you are in is marked and in view when the list opens (#647).
- **Side panel on tablets:** in landscape, the page list beside the page is now a panel with Pages, Contents and Bookmarks. The Contents button opens it and folds it away (#647).
- **Bookmark this page from the list:** the Bookmarks tab's first row adds or removes the bookmark of the page in view (#647).
- **A new highlight stays in hand:** after a highlight, underline, strikethrough or squiggly made with the Highlight tool, a bar by it offers five colours, Add note and Delete. The next touch on the page starts the next markup (#650).
- **Colours one tap away:** the Highlight tool's row shows up to five colours before the colour button, as many as fit: three on a phone 384 dp wide (#650).
- **Enhance scanned pages shows its progress:** it counts the scanned images and can be stopped with Cancel. A stopped run changes nothing (#646).

## Fixes

- **Cancel inside long steps:** Cancel now stops Extract pages, Split, Combine, Create PDF, Compress, Print options, Compare and Set a password while they copy the pages, write the file, find the changes or save the protected copy, and the progress bar moves through those steps. Before, Cancel waited for the step to end (#646).
- **The bar by a new markup after Undo:** Undo and Redo now close it. After an undo its Delete could act on another comment (#650).

## Improvements

- **Correction to the 0.0.40-beta notes:** the 0.0.40-beta notes said "Every long job shows its progress and can be stopped". 18 short jobs show only the time taken and cannot be stopped, among them signing, exporting, importing and summarizing comments, restoring a backup, and the contents' own tools. One of them, Contents from headings, reads every page of the document (#646, #652).
- **Diagnostics log:** a stopped job says how far into its step it was. Opening the contents, the bar by a new markup and the quick colours are logged.

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only. The new top bar, the contents list, the tablet's side panel and the Highlight tool's bar have not been seen on a device.
- **Cancel inside long steps:** how soon it takes hold on a large file has not been measured.
- **Contents from headings** shows no progress and cannot be stopped (#652).
- **Contents:** a tablet in portrait gets the sheet, not the side panel. The tab last used is kept only while the document is open.
- **Highlight tool:** a tap on an existing markup marks the word under it; it does not select that markup.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.41-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.41-beta (41012)` match, then approve the installation in Android. It installs over 0.0.40-beta (40012) with the same package and signing certificate.
