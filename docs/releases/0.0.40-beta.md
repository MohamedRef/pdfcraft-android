# PdfCraft Android 0.0.40-beta (40012)

## New features

- **Every long job shows its progress and can be stopped:** Split, Extract pages, Export (Word, Excel, PowerPoint, RTF, text), Print options, Compare, Combine, Create PDF and Set a password now say how far they are and can be stopped with Cancel, as Compress already did in 0.0.39-beta. A stopped run leaves no file behind (#634; #641, #642, #643, #644).

## Fixes

- **Long jobs counted:** the 0.0.39-beta notes listed Split, Extract, Export, Print, Compare and Protect as not yet counted. They are now (#634).

## Improvements

- **Diagnostics log:** each of these jobs logs how it ended, its time and the bytes it read.

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only.
- **Set a password:** saving the protected copy is one step that encrypts the whole file, so Cancel takes effect only when that step ends.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.40-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.40-beta (40012)` match, then approve the installation in Android. It installs over 0.0.39-beta (39012) with the same package and signing certificate.
