# PdfCraft Android 0.0.17-beta (17012)

## New features

- **Record and share open timings:** Settings → About → Diagnostics has a new switch, *Record open timings* (off by default). While it is on, PdfCraft keeps how long each step of opening a file takes: copying from the other app, the engine's open, and the first page drawn. *Share open timings* sends them as a text report with the app and engine versions, phone model, Android version and memory. Only step names, times, sizes and page counts are kept, never file names or contents. Turning the switch off clears them.

## Fixes

- None in this release beyond the build housekeeping below.

## Improvements

- The new texts are translated into Arabic, German, Spanish, French, Italian and Brazilian Portuguese.
- Python cache files are no longer tracked in the repository.

## Known limits and testing

- This release measures slow opens; it does not make them faster yet. Large files opened from another app are still copied in full on every open (#210), the first page waits for that copy (#211), and the engine reads the whole file into memory (#212). The timings shared from this build decide the order of those fixes.
- Automated Rust/provenance, Android JVM and signed ARM64 release checks passed. The Diagnostics screen and sharing have not been tried on a physical device.
- All limits listed for 0.0.16-beta (16012) still apply; reviewer issues #70–#205 remain open.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.17-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.17-beta (17012)` match, then approve the installation in Android. It installs over 0.0.16-beta (16012) with the same package and signing certificate; earlier releases are not replaced.
