# PdfCraft Android 0.0.43-beta (43012)

## New features

- **Calligraphy pen:** a sixth pen, after the fountain pen, with a flat nib held at 45°: a stroke across the nib is thick, one along it a fifth as wide, so downstrokes and upstrokes differ as with a real nib. Pressure changes it a little; the ends are not pointed. The Pen lab has a new Width change dial for how fast the width may turn (#678).
- **Dashed and dotted lines:** every pen but the highlighter has Line: Solid, Dashed or Dotted in its settings, kept per pen. The line is shown dashed while it is written and cut into its dashes when the pen lifts; it is saved as one drawing that other PDF readers show the same way, and Undo takes the whole line back (#682).
- **More shapes and solids:** Shapes › More shapes holds a triangle, right triangle, diamond, pentagon, hexagon, double arrow and coordinate axes, saved as shapes you can reshape later, and nine solids for diagrams (cube, prism, pyramid, cylinder, cone, sphere, hemisphere, frustum, tube) with their hidden edges dashed. Each is drawn by one drag and taken back by one Undo (#693).
- **Resize and turn a lasso selection:** a selection has a handle at its corner, which makes it bigger or smaller keeping its proportions, and one above it, which turns it (snapping to quarter turns). Drawings, lines and polygons turn and scale with their line width; rectangles, ovals, text boxes and stamps are resized but not turned (#689).
- **Unsaved ink kept through a crash:** strokes not saved yet are kept in a small file as you write. If the app closes unexpectedly (a crash, Android stopping it, the phone switching off), they are added back the next time the same document is opened, with a message saying how many. Pen lab › Keep unsaved ink through a crash turns it off (#680).

## Fixes

- **The eraser cuts where its edge is:** a stroke is now cut exactly where the eraser's circle meets it, for saved ink and for strokes not saved yet, instead of up to half the eraser's size away. A small eraser over long strokes is no longer refused (#676).
- **Pen tilt per sample:** each pen sample keeps its own tilt instead of the newest one's, for pens whose Tilt dial is set in the Pen lab (#674).
- **Memory after showing or hiding a layer:** old page images kept on screen while new ones are drawn now count toward the image memory limit, so a layer toggle while zoomed in no longer holds up to twice as much (#685).

## Improvements

- **Eraser over many strokes:** the eraser skips strokes it is far from without going through their points, which mattered on pages written for a long time (#687).
- **Diagnostics log:** the empty low-latency fields of each pen stroke are gone (#674); new lines say what the new features did (`ink_pattern`, `lasso_transform`, `ink_journal`, `ink_journal_closed`, `width_slope`, the new shapes on `shape`), counts only.
- **Build checks:** more checks run on every build (an unclosed cursor, a wake lock left on, work done while drawing, version checks that can never fail) (#691).

## Known limits and testing

- **Nothing in this release was tried on a phone or tablet.** It is checked by the Rust and Android JVM tests in CI only; each pull request lists what was not verified.
- Worth checking first on the phone: the calligraphy pen's angle for your Arabic and Latin writing (Pen lab › Nib angle changes it); dashed lines while writing and after lift; the lasso's handles under a finger and the S Pen; how the solids look at your pen width; the crash journal after force-stopping the app while writing in Draw.
- Not done yet: the first seven shapes (line, rectangle, oval, arrow, cloud, polygon, connected lines) do not follow the pen's Line choice; the calligraphy nib does not turn with the pen's own rotation; a solid cannot be turned in 3D after it is drawn.
- Source: `main` at `506b83e` (#694) and this release's commit; the changes are tracked in #684. Automated Rust/provenance, Android JVM and signed ARM64 release checks must pass before publishing.

## Installing

After the source, test, release-signing, ABI, manifest and checksum gates succeed, the in-app updater offers `pdfcraft-android-0.0.43-beta.apk` (arm64-v8a) from the official PdfCraft Android fork's GitHub Release. You can also download it there. Check that the SHA-256 and the manifest version `0.0.43-beta (43012)` match, then approve the installation in Android. It installs over 0.0.42-beta (42012) with the same package and signing certificate.
